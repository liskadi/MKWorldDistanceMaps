# MKWorldDistanceMaps

Interactive course distance maps, decompiled `LapPathGraph` lap/section lengths, and `+250m` (`+1`) / `+300m` (`+2`) item pool promotion markers for *Mario Kart World* (`v1.8.0`), derived from decompiled game parameters (`main.elf` & `general_format.Product_180.sarc.zs`).

Companion app: **[MKWorldItemProb](https://liskadi.github.io/MKWorldItemProb/)**

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
